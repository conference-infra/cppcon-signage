# Cppcon Digital Signage

Greetings from the past!

This was a static site I threw together (with the help of AI - it shows, but I wouldn't have been able to otherwise with my schedule). The site loads all the information from the json in `schedule.json` and is meant to be loaded on the digital signage provided by <> using <>.

You can build a new schedule from the sched api by placing an api key in `api_key.txt` and running the `sched_api_events_to_json.py`. The key is of course in the gitignore - don't check it in.
